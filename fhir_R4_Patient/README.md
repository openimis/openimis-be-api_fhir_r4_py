# OpenIMIS FHIR R4 Patient Module

The openIMIS Backend FHIR R4 Patient module provides FHIR R4 compliant Patient resource management for the OpenIMIS system.

## Features

- FHIR R4 Patient resource support
- Integration with OpenIMIS core modules
- RESTful API endpoints for Patient operations

## Installation

This module is part of the OpenIMIS backend system and should be installed as part of the complete OpenIMIS installation.
