# OpenIMIS FHIR R4 Claim Module

The openIMIS Backend FHIR R4 Claim module provides FHIR R4 compliant Claim resource management for the OpenIMIS system.

## Features

- FHIR R4 Claim resource support
- Integration with OpenIMIS core modules
- RESTful API endpoints for Claim operations

## Installation

This module is part of the OpenIMIS backend system and should be installed as part of the complete OpenIMIS installation.
